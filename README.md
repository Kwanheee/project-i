# 읽고 생각하기 (Project I)

읽은 책에서 뽑은 인용과 거기서 난 생각을 모아, 글의 재료로 삼는 곳.

```
📚 자료 (sources) ──▶ ✂️ 인용 (excerpts) ──▶ 💡 생각 (ideas) ──▶ ✍️ 글 (writings)
                                                 └── 관련 생각 (자기참조)
```

- **자료** 한 권 = 파일 하나. 본문에 챕터 요약.
- **인용** 구절 하나 = 파일 하나. `source`로 자료를 가리킨다.
- **생각** 질문 하나 = 파일 하나. `evidence`로 인용을, `related`로 다른 생각을 가리킨다. `claim`에 한 줄 주장을 쓰는 것이 목표.
- **글** 한 편 = 파일 하나. `materials`로 생각을 가리킨다. 본문이 초고.

모든 데이터는 `content/` 아래 마크다운 파일이다. 사이트는 이 파일들을 읽어 관계와 집계(책이 낳은 생각 수, 생각의 근거 수, 글감 후보 등)를 빌드 시점에 계산한다.

## 쓰는 법

1. `content/<폴더>/_template.md` 를 복사해 새 파일을 만든다. 파일 이름은 영문 소문자와 하이픈만 쓴다. 파일 이름이 그 항목의 id다.
2. 참조(`source`, `evidence`, `related`, `materials`)는 다른 파일의 이름(확장자 제외)을 적는다. 없는 id를 적으면 빌드가 실패하면서 알려준다.
3. `_` 로 시작하는 파일은 무시된다.

## 로컬에서 보기

```bash
npm install
npm run dev
```

## 배포

`main` 브랜치에 push 하면 GitHub Actions가 빌드해서 GitHub Pages에 올린다.
설정은 `.github/workflows/deploy.yml`, 주소는 `astro.config.mjs` 의 `site` + `base`.
